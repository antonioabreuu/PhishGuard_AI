# PhishGuard AI - Detector de Phishing

## 🎯 Objetivo

Modelo de Machine Learning (Random Forest) desenvolvido com apoio do **Gemini** e **Antigravity** para identificação de padrões e detecção de anomalias (riscos) em links. 

O diferencial do projeto é o uso de explicabilidade de IA (SHAP): o sistema não apenas toma uma decisão, mas demonstra com transparência quais variáveis de dados motivaram o alerta. Esse projeto aprofundou minha visão analítica sobre como utilizar dados para prever desvios de padrão, uma lógica diretamente aplicável à gestão de riscos, auditoria e previsibilidade de cenários.

### ⚠️ Aviso Ético
Este é um laboratório educacional. Não utilize como única camada de defesa e nunca realize ataques contra terceiros.
